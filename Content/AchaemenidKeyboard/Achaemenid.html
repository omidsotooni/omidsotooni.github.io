About Project

Achaemenid Keyboard provides modern digital input support for the Old Persian Cuneiform writing system used during the Achaemenid Empire (c. 550–330 BCE).

The project generates Unicode-based keyboard layouts for multiple operating systems while preserving the same keyboard mapping.

Features

  • Fully Unicode compliant
  • Official Old Persian Unicode support
  • 36 Old Persian signs
  • 5 Old Persian numerals
  • Word divider support
  • Cross-platform keyboard generation

Unicode Support

The keyboard uses the official Old Persian Unicode block:

U+103A0 – U+103DF

No Private Use Area (PUA) characters are used. All characters are represented using official Unicode code points.
