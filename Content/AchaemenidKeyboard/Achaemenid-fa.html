درباره پروژه

کیبورد هخامنشی یک پروژه برای فراهم کردن امکان ورود دیجیتال خط میخی پارسی باستان در محیط‌های مدرن است.

خط میخی پارسی باستان در دوره هخامنشیان (حدود ۵۵۰ تا ۳۳۰ پیش از میلاد) برای کتیبه‌های سلطنتی، فرمان‌ها و نوشته‌های رسمی استفاده می‌شد.

این پروژه با استفاده از استاندارد رسمی Unicode، صفحه‌کلیدهایی برای سیستم‌عامل‌های مختلف تولید می‌کند و نگاشت کلیدها را در تمام پلتفرم‌ها یکسان نگه می‌دارد.

ویژگی‌ها

  • پشتیبانی کامل از Unicode
  • استفاده از نویسه‌های رسمی خط میخی پارسی باستان
  • پشتیبانی از ۳۶ نشانه پارسی باستان
  • پشتیبانی از ۵ عدد پارسی باستان
  • پشتیبانی از جداکننده واژه‌ها
  • تولید صفحه‌کلید برای چندین سیستم‌عامل

پشتیبانی Unicode

این صفحه‌کلید از بلوک رسمی Unicode برای خط میخی پارسی باستان استفاده می‌کند:

U+103A0 – U+103DF

تمامی نویسه‌ها از کدهای رسمی Unicode استفاده می‌کنند و هیچ نویسه‌ای از محدوده Private Use Area (PUA) در پروژه وجود ندارد.
